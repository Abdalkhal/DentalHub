# خطة تطبيق DentalHub - واجهة الطبيب

تطبيق موبايل (RTL/LTR) يربط أطباء الأسنان بالمستلزمات الطبية، المختبرات، ووكلاء زراعة الأسنان. هذه المرحلة الأولى: واجهة الطبيب فقط ببيانات تجريبية (بدون قاعدة بيانات أو تسجيل دخول).

## الستايل البصري

- **الألوان**: Cloud White (#fafbfc, #e8ecf1, #94a3b8, #3b82f6) - خلفية فاتحة بأزرق أساسي
- **الخطوط**: Urbanist (عناوين) + Epilogue (نص) — مع Cairo/Tajawal للعربي
- **التخطيط**: Hero Grid - بانر علوي + شبكة بطاقات
- **الإطار**: محاكاة موبايل، تاب بار سفلي، زوايا ناعمة، ظلال خفيفة

## الصفحات (Routes)

### 1. الصفحة الرئيسية `/`

- شريط علوي: شعار DentalHub + زر AR/EN + بحث
- بانر متحرك (Carousel) للعروض (مثل عرض زرعات Alfa Gate $399)
- شبكة بطاقات للأقسام الأربعة:
  - المستلزمات الطبية
  - المختبرات
  - الزراعة
  - حسابي
- تاب بار سفلي: الرئيسية / طلباتي / حسابي / المزيد

### 2. المستلزمات الطبية `/supplies`

قائمة بالمكاتب في الموصل:

- مكتب بوابة الموصل
- مكتب بلوتوث
- مكتب الصدى
- مكتب مينا

### 3. صفحة المكتب `/supplies/$officeId`

- شريط بحث في الأعلى
- تبويبات/بطاقات لفروع طب الأسنان:
  - Endodontic / Prosthodontic / Surgery / Orthopedic / Pedodontic / Periodontic / مواد عامة

### 4. صفحة الفرع `/supplies/$officeId/$branchSlug`

- قائمة بالمستلزمات الخاصة بهذا الفرع (اسم، صورة، سعر، زر إضافة لطلب)

### 5. المختبرات `/labs`

- قائمة المختبرات مع تقييم/مسافة

### 6. صفحة المختبر `/labs/$labId`

- معلومات المختبر، جدول الأسعار، نوعية العمل (Zirconia, PFM, E-max ...)
- زر "إرسال حالة"

### 7. تتبع الحالات `/labs/cases`

- قائمة الحالات مع شريط حالة (Timeline):
  - ✓ تم استلام الحالة → ✓ قيد التنفيذ → ✓ تم الانتهاء → 🚚 في الطريق → 📦 تم التسليم

### 8. الزراعة `/implants`

- بطاقات حسب البلد: كورية / سويسرية / إيطالية / ألمانية / برازيلية (مع علم البلد)

### 9. زرعات بلد محدد `/implants/$country`

- قائمة الماركات (Alfa Gate, Straumann, MIS, Neodent...)
- لكل ماركة: نوع (فورية / غير فورية)، أحجام، السعر

### 10. حسابي / طلباتي / المزيد

- صفحات بسيطة مع بيانات وهمية

## التفاصيل التقنية

- TanStack Start file-based routing تحت `src/routes/`
- بيانات وهمية في `src/data/` (offices.ts, labs.ts, implants.ts, cases.ts)
- مكتبة i18n خفيفة (`src/lib/i18n.ts`) + LanguageContext لتبديل AR/EN وتطبيق `dir="rtl"`
- مكونات مشتركة: `MobileShell` (إطار الموبايل)، `TopBar`، `BottomTabBar`، `SectionCard`، `OfficeCard`، `CaseTimeline`
- shadcn: Card, Tabs, Input, Button, Badge, Carousel
- صور توضيحية مولّدة لشعار التطبيق وأيقونات الأقسام (مستلزمات/مختبر/زرعة)
- بيانات تجريبية فقط — لا Lovable Cloud في هذه المرحلة
